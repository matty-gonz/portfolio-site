# robots.txt — matthewjgonzalez.me
#
# Policy: don't feed model training. Stay findable.
#
# AI companies run separate crawlers for separate jobs, and each can be
# controlled independently:
#
#   TRAINING  — harvests pages to train future models.
#               Blocking costs you nothing.
#   SEARCH    — builds the index an assistant searches when answering.
#               Blocking makes you invisible in AI answers.
#   USER      — fetches a page live because someone asked about you
#               right now. This is the one that matters most for a
#               portfolio, and the one people block by accident.
#
# So: training bots are denied, search and user-triggered bots are
# allowed. Someone asking an assistant about you still finds this site;
# nobody trains on it.
#
# NOTE: robots.txt is voluntary. Reputable crawlers honour it; scrapers
# ignore it. Enforcement against the ones that lie happens at Cloudflare
# (Security -> Bots), not here.
